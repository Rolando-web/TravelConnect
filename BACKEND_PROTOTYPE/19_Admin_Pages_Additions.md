# Admin Panel — New Pages (add after item 24)

---

   25. Super Admin Support Page
Access: Super Admin — Manage | Agency Admin — Manage | Agency Staff — Manage | Finance Staff — Manage | Supplier — Manage Own
The Support Page allows administrative users to raise and track their own support requests. Users can submit a ticket by category, follow its status, and read replies from the support team. Each user sees only their own tickets.

   26. Super Admin Tier Support Hub Page
Access: Super Admin — Manage
The Tier Support Hub Page is the Super Admin's workspace for subscription and plan inquiries. It lists all tier-related conversations, allows the Super Admin to review the full thread, and send replies using suggested quick responses.

   27. Agency Admin Support Hub Page
Access: Agency Admin — Manage
The Agency Support Hub Page is the Agency Admin's workspace for customer problems such as refunds and general issues. It lists the agency's own customer conversations, allows the Agency Admin to review the thread, and send replies. Super Admin has no access to this page.

   28. Super Admin Subscriptions Page
Access: Super Admin — Manage
The Subscriptions Page manages the subscription plans offered to agencies. The Super Admin can create, edit, and delete the Starter, Professional, and Enterprise plans, view the modules unlocked by each tier, and monitor each agency's subscription status.
