## Algorithms Used

### QuestPDF Document Building
```csharp
public byte[] GenerateItineraryPdf(Booking booking, List<BookingFlight> flights)
{
    QuestPDF.Settings.License = LicenseType.Community;

    var document = Document.Create(container =>
    {
        container.Page(page =>
        {
            page.Size(PageSizes.A4);
            page.Margin(40);
            page.DefaultTextStyle(x => x.FontSize(10).FontFamily("Arial"));

            // Header: Logo + E-TICKET label
            page.Header().Element(header => { /* ... */ });

            // Content: Passenger + Booking details
            page.Content().Element(content =>
            {
                // Passenger Info (2-column row)
                content.Row(row => { /* Name, Email, Phone */ });

                // Flight Itinerary Table
                if (flights.Count > 0)
                {
                    content.Table(table =>
                    {
                        table.ColumnsDefinition(columns =>
                        {
                            columns.RelativeColumn(3);  // Flight
                            columns.RelativeColumn(2);  // Date
                            columns.RelativeColumn(2);  // Time
                            columns.RelativeColumn(1);  // Class
                            columns.RelativeColumn(1);  // Seat
                        });
                        // Header row + data rows
                    });
                }

                // Payment Summary
                content.Row(row => { /* Subtotal, Discount, Total */ });

                // Terms & Conditions
                content.Text("TERMS & CONDITIONS").Bold();
            });

            // Footer: Timestamp
            page.Footer().Element(footer => { /* ... */ });
        });
    });

    using var stream = new MemoryStream();
    document.GeneratePdf(stream);
    return stream.ToArray();
}
```

### PDF Layout Structure
```
A4 Page (210mm × 297mm)
├── Header (40px margin)
│   ├── Left: TravelConnect logo + tagline
│   └── Right: "E-TICKET" + Reference Number
├── Content (40px margin)
│   ├── Row: Passenger Details | Booking Details
│   ├── Flight Itinerary Table (if flights exist)
│   │   ├── Header: Flight | Date | Time | Class | Seat
│   │   └── Rows: Up to 6 segments
│   ├── Row: Payment Summary | Total Paid
│   └── Terms & Conditions (4 items)
└── Footer
    └── "Generated by TravelConnect | {UTC timestamp}"
```
